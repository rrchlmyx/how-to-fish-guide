# Summon Desk — Anime Origins Roblox guides

Third guide site from the 生财有术《AI 产品（国外—热词游戏站）》workflow. Separate Next.js app for its own Vercel project.

## Why this game

- Keyword: Anime Origins (US KD ~11, ~390 monthly searches on Natiad, Aug 2026)
- Live Roblox tower defense by Origins Project (place `129932912185311`)
- Clear search intents: codes, redeem, beginner, traits, summons, Story Mode

## Local

```bash
cd sites/anime-origins-guide
npm install
npm run dev
```

Open http://127.0.0.1:3002

## Vercel

- New project from the same GitHub repo
- Root Directory: `sites/anime-origins-guide`
- Framework: Next.js
- Optional env: `NEXT_PUBLIC_SITE_URL=https://<your-host>`

## Editorial rule

AI organizes cross-checked writeups. Reward numbers that disagree across outlets are flagged. In-game popups win. Codes are dated because they expire.
